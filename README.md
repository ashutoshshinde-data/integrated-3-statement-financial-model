Integrated 3-Statement Financial Model
Project Overview

This project presents an integrated 3-Statement Financial Model developed in Microsoft Excel to analyze historical financial performance and build forward-looking financial projections.

The model connects the Income Statement, Balance Sheet, and Cash Flow Statement to demonstrate how operating, working capital, and financing assumptions flow through a company's financial position.

The model is structured around a professional financial modeling workflow, with an emphasis on financial statement integration, forecasting, and analytical review.

Financial Modeling Focus
Income Statement

Analyzed historical operating performance and developed forward-looking projections for revenue, expenses, profitability, and key financial metrics.

Balance Sheet

Projected major asset, liability, and equity accounts based on operating and financing assumptions.

Cash Flow Statement

Modeled operating, investing, and financing cash flows to evaluate projected cash generation and liquidity.

Integrated Financial Model

Linked the three financial statements to demonstrate how changes in operating assumptions flow consistently throughout the model.
